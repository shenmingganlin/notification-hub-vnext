## 1. 一句话

路径：

```text
选出现方式 → 只调这一组 → 看见它动 → 保存
```

## 2. 第一屏（硬布局）

```text
通知视觉                              [保存]
堆叠 | 弹幕

[ 只属于当前出现方式的一组旋钮 ]
[ 卡片外观：尺寸 / 圆角 / 背景 ]

预览（只演当前这一种，可动）     [试一条]
```

配置包、应用到事件、诊断：**默认折叠**，不占第一屏。

## 3. 交互硬约束

1. **出现方式只留一个入口。** 芯片 `堆叠 | 弹幕`。删除：左栏起步预设卡、重复的「卡片外观编辑器」标题、隐藏 select 作为可见入口（生产落地时可留 aria-hidden 同步用，原型里不要画出来）。
2. **编辑器跟当前方式走，不手风琴。** 无关控件是「不出现」，不是「折叠」。
3. **预览只演当前这一种。** 禁止三张静态字母卡并排。弹幕预览必须能看出「从右往左流」；堆叠预览是右下叠卡。
4. **试一条贴在预览旁。** 不再滚到独立「视觉实验台」才试。
5. **保存贴着标题行。** 仍是全页唯一实心主按钮。
6. **突脸可见但不可选**，角标「未实现」+ 非颜色文字说明。不得伪装成可点。
7. **名实一致。** 看得见的都能用。`hoverPause` / `overflow` 不露。通道内部名（`stack.main`）不作为主文案。

### 3.1 选堆叠时露出

- 停靠（四角，空间控件优先于四个数字框）
- 边距 / 卡片间距（可次级）
- 关闭方式
- 停留时长（堆叠仍用；不要同时摆「持续时间」和「停留时长」两个同义项，只留一个）

### 3.2 选弹幕时露出

- 弹幕带位置（顶 / 底，用带状控件，不要纯下拉）
- 弹幕带高度 15–100%
- 速度 150–800 px/s（滑杆为主，旁注「400 ≈ 4.8 秒过屏」）
- 轨道数（0 = 自动，**不设上限**，输入框无 `max`）
- 同轨间距 24–160 px

弹幕下**禁止出现**：停靠角、四边距、排列方式、持续时间、停留时长。

### 3.3 两种方式都露出（卡片外观）

尺寸、宽、高、圆角、透明度、背景色 / 素材 / 裁剪。这一组在出现方式旋钮之下，视觉权重更低。

## 4. 排版硬约束

| 禁止 | 改为 |
|---|---|
| `VISUAL WORKBENCH / 01`、10px 大写 kicker、等宽眉题 | 一个页标题 22–24px + 一句副文案 13–14px |
| h1 + h2 + h3 + summary + 分组名五级抢层级 | 页标题 / 分组名 13px / 字段标签 12px，最多三级 |
| 卡片套管道套手风琴套子分组描边盒 | 一个主表面；分组靠留白，不再套框 |
| 三列数字田、标签 11px | 最多两列；标签 ≥12px；控件高 36px |
| 工程口吻（Native preview、草稿不写历史、三通道说明书） | 用户句 |

色板沿用现页，不换肤：

```text
bg #0e1513 / surface #17221f / raised #1d2b27
text #e7f2ee / muted #9bb1a9 / line #304740
accent #62d0a8 / strong #38b88d
ticker #56c8d8 / popup #f1c77a（仅未实现态）
```

圆角：外壳 6–8px，不要装饰光晕、渐变、大阴影。
