# 通知视觉 · 卡片工作室 视觉规格

日期：2026-09-12  
对照原型：`docs/superpowers/prototypes/visual-studio-elegance.html`  
对照硬约束：`docs/superpowers/specs/2026-09-12-visual-studio-elegance.md`  
本文件只验收画面与交互态。不升版本、不改生产页。

色板（锁死，不得换肤）：

```
bg #0e1513 / surface #17221f / raised #1d2b27
text #e7f2ee / muted #9bb1a9 / line #304740
accent #62d0a8 / strong #38b88d
ticker #56c8d8 / popup #f1c77a（仅未实现角标）
```

## 3. 第一屏结构（硬验收）

从上看下去必须是：

1. 「通知视觉」 + 一句副文案 + 唯一实心按钮「保存」
2. 芯片：堆叠 | 弹幕 | 突脸（未实现）
3. **只属于当前出现方式**的一组旋钮
4. 卡片外观（尺寸 / 圆角 / 背景），权重更低
5. 预览（只演这一种，可动）+ 贴在预览旁的「试一条」

配置包、应用到事件、诊断：默认折叠，不占第一屏。

---

## 4. 控件 ↔ 用户句

禁止把内部名写进可见文案。下面每条都必须能在原型里找到对应控件。

| 可见文案 | 用户句 | 出现条件 |
|---|---|---|
| 堆叠 | 卡片从角落叠上来，停在那里等你看完 | 始终可选 |
| 弹幕 | 卡片从右往左流过，看过即走 | 始终可选 |
| 突脸 + 角标「未实现」 | 突脸还在开发中，暂时不能选择 | 始终可见，不可选中 |
| 保存 | 把当前这组写进去 | 标题行，全页唯一实心主按钮 |
| 试一条 | 立刻看一张卡怎么动 | 预览标题右侧 |
| 停靠（四角） | 卡片从屏幕哪个角长出来 | 仅堆叠 |
| 关闭方式 | 怎么让这张卡离开 | 仅堆叠 |
| 停留时长 | 叠在那里多久后自动收走 | 仅堆叠；全页只留这一个时长 |
| 边距与卡片间距 | 离屏幕多远、叠在一起隔多开 | 仅堆叠，默认折叠 |
| 弹幕带位置 | 从屏幕顶还是底流过去 | 仅弹幕 |
| 弹幕带高度 | 这条流动带占多高 | 仅弹幕，15–100% |
| 速度 | 过屏有多快 | 仅弹幕，150–800；旁注「400 ≈ 4.8 秒过屏」 |
| 轨道数 | 同时能并排几条 | 仅弹幕；0 = 自动；输入无 max |
| 同轨间距 | 同一条线上前后两张卡隔多远 | 仅弹幕，24–160 |
| 尺寸 / 宽 / 高 | 这一张卡多大 | 两种方式都有，权重低于旋钮 |
| 圆角 / 透明度 | 边有多软、底有多透 | 同上 |
| 背景色 / 素材 / 裁剪 | 底是纯色还是图，图怎么裁 | 同上 |
| 配置包 | 存一份、换一份 | 次级折叠 |
| 应用到事件 | 哪类通知用这套样子 | 次级折叠 |
| 诊断 | 最近一次视觉操作记在这 | 次级折叠 |

弹幕下**不得出现**：停靠、四边距、排列方式、持续时间、停留时长。  
堆叠下**不得出现**：弹幕带、速度、轨道数、同轨间距。  
全页**不得出现**：持续时间与停留时长并列、`hoverPause`、`overflow`、三种行为并排预览。

## 5. 组件状态

### 5.1 出现方式芯片（堆叠 / 弹幕）

| 态 | 边框 | 底 | 字 | 其它 |
|---|---|---|---|---|
| 默认 | line 1px | raised | text 13/600 | 高 36，圆角 7 |
| 悬停 | accent | raised | text | 无光晕 |
| 选中 | strong + 底边 inset 2px accent | raised | text | `aria-pressed=true` |
| 按下 | 同选中 | raised | text | 下移 1px |

同一时间只能选中一个已实现芯片。

### 5.2 突脸（锁定）

| 态 | 要求 |
|---|---|
| 默认 | 虚线边框、透明底、muted 字、角标「未实现」（11px + 文字，不能只靠 popup 色） |
| 悬停 | 边框仍是 line，不进入 accent，不假装可点 |
| 选中 | **禁止**。点击只在预览下用文字说明「突脸还不能用」 |
| 说明 | 芯片下始终有一句 12px muted：「突脸还在开发中，暂时不能选择。」 |

### 5.3 输入 / 下拉

| 态 | 要求 |
|---|---|
| 默认 | 高 36，圆角 6，底 raised，边 line，字 13–14 text |
| 悬停 | 边仍 line（不发光） |
| 焦点 | 2px accent outline，offset 2 |
| 禁用 | opacity 0.48，`not-allowed` |
| 标签 | 始终 ≥12px muted，放在控件上方 |

### 5.4 滑杆（高度 / 速度 / 同轨间距）

| 态 | 要求 |
|---|---|
| 默认 | 轨道行高 36；右侧 64px 读数盒 |
| 悬停 | 拇指跟随系统 accent，无光晕 |
| 拖动 | 读数即时变；弹幕预览速度 / 带宽跟着变 |
| 禁用 | 本页不用。不要画灰掉的假滑杆 |

速度旁必须有「400 ≈ 4.8 秒过屏」。高度显示百分号。同轨间距显示纯数字（单位在标签里）。

### 5.5 停靠四角

| 态 | 要求 |
|---|---|
| 默认 | 2×2 小屏幕，四格 line 边 |
| 悬停 | 该格边框 accent |
| 选中 | 边 strong + 内 1px accent；预览堆叠角跟着换 |
| 禁用 | 弹幕模式下整组不渲染（不是灰掉） |

### 5.6 弹幕带位置

| 态 | 要求 |
|---|---|
| 默认 | 竖向屏幕剪影，顶/底两块可点 |
| 悬停 | 对应半区文字变 text |
| 选中 | 色带贴在顶或底，高度跟「弹幕带高度」滑杆 |
| 禁用 | 堆叠模式下整组不渲染 |

### 5.7 主按钮「保存」

| 态 | 要求 |
|---|---|
| 默认 | 实心 strong，字 ink，高 36，圆角 7。全页只有这一个实心 |
| 悬停 | 底改 accent |
| 按下 | 下移 1px |
| 刚保存 | 可短暂改成描边「已保存」，1.4s 内回到实心「保存」 |
| 禁用 | 本页不用 |

「试一条」「存为配置包」「预览影响」「应用」「刷新/清空/导出」全部是幽灵按钮（透明底 + line 边），不得做成第二颗实心。

### 5.8 折叠次级

| 态 | 要求 |
|---|---|
| 默认 | 关闭。44px 行，13px 标题 + 12px muted 副句 |
| 悬停 | 标题色改 accent |
| 展开 | 内容在标题下用留白铺开，不再套描边大卡片 |
| 禁用 | 不画点不动的折叠 |

## 6. 预览运动

| 方式 | 必须看见 | 禁止 |
|---|---|---|
| 堆叠 | 右下（或当前停靠角）叠卡；试一条再叠一张 | 三张静态字母卡并排；同时演弹幕 |
| 弹幕 | CSS 动画从右往左流；带宽在顶或底；轨数随输入，**无 max=4** | 画成「最多 4 条」的轨道尺；同时演堆叠 / 突脸 |

预览台只有一个。切芯片时旋钮组和预览一起换，无关控件是「不出现」不是「折叠」。

---

## 7. 820px / 560px 怎么收

### 820px

- 仍是单栏工作室，不回到「左预设 / 中编辑 / 右预览」三栏。
- 字段保持两列。
- 页边收到 20px。预览台高收到 240。
- 停靠、弹幕带控件保持空间形态，不退化成四个数字当主角。
- 不破版：不出现横向滚动；芯片可换行。

### 560px

- 标题与保存上下排。保存、试一条拉满宽。
- 字段改一列。
- 停靠、弹幕带拉满宽，高度不压扁到无法点。
- 预览台高 220。预览标题与试一条上下排。
- 折叠次级的副句换到下一行，不把标题挤出视口。
- 不破版：最小宽 320；控件保持 36 高；标签不截成 11px。

## 8. 对照规格第 5 节反例（自检）

| 反例 | 本稿 |
|---|---|
| 首屏同时摆三种行为完整预览 | 否。预览只演当前一种 |
| 左栏起步预设与顶轴重复 | 否。无起步预设栏 |
| 配置包 / 事件 / 诊断与编辑器同级长表单 | 否。默认折叠 |
| 可点但无效的控件 | 突脸不可选；hoverPause / overflow 不露 |
| 为了好看把弹幕轨道画成最多 4 条 | 轨道数输入无 max；预览按数值铺轨，带内裁切 |
| 新造第三种出现方式或新卡片种类 | 否。突脸只作未实现占位 |

## 9. 生产落地时不要抄回去的东西

- 本文件是静态稿规格，不替代 `settings-visual.js`。
- 「已保存」动效、试一条加卡，只证明手感，不接 Native。
- 配置包 / 应用 / 诊断在原型里是结构占位，文案用用户句，不写通道说明书。
