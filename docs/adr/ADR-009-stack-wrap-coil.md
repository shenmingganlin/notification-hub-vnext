# ADR-009：堆叠走线回字（coil）

- 状态：Accepted
- 日期：2026-09-17
- 范围：堆叠通道 `wrap: coil`；JS 预览布局；Native `layout_coil_wrap`；工作室走线芯片
- 关联：ADR-006（规约户口）、ADR-008（新位）
- 产品版本：0.1.8（不升号）

## 背景

走线已有关、平行、蛇形。蛇形是平行条来回折。用户要的是剩框往里收：从停靠沿往哪长出发，转向内里，越绕越小。这不是新飞法，也不改占角/新位。

## 决策

1. **`wrap: coil`。用户词回字。** 口头外号回子弯。不要螺旋当芯片。
2. **走线与新位独立。** 占角站外角，旧卡往心里让；新位则旧卡不动，新卡往心里走。方向映射仍只看 newest，不看 wrap。
3. **第一边 = grow，下一边 = 角落允许的另一向（内里），然后反向。** Native 用 `newest` + `direction` 还原 grow：`next` 则 grow=direction，`dock` 则 grow=opposite(direction)。
4. **一边的厚度按这排最厚的卡，小卡旁边留洞。** 不俄罗斯方块。满了掀最旧，剩下重新绕紧。
5. **默认仍 parallel。** 关开新列时走线三颗全灰。
6. **`wrap==coil` 一律走回字收框，** 不要先线性成功就返回。卡少则只占第一边。
7. **卡顿铁律：** 排版只在来卡/掀卡/改规约时算。跟随只挪窗口。

## 后果

- 钉死包、follow 试包、newest 试包不准覆盖。试包打 `dist/notification-hub-vnext-0.1.8-coil.zip`。
- Native 不新增 `.cpp`。枚举值加在 `StackWrap` 末尾。
